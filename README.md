# Vellum

本机运行的图像创作工作台，支持提示词编辑、画师组合、图像参考、生成与作品整理。

## 启动

需要 Windows x64 与 Node.js 24 或更新版本。

```sh
git clone https://github.com/XTOGENY/Vellum.git
cd Vellum
npm ci
npm run build
npm start
```

打开 [http://127.0.0.1:8780/](http://127.0.0.1:8780/)，在设置中配置自己的模型连接。也可以运行 `start.cmd`。

## 数据

连接、模板、画师资料、草稿和作品均在使用时保存在本机，仓库不附带个人资料。首次启动为空白工作空间。密钥使用当前 Windows 用户的 DPAPI 加密保存。

不要上传 `data/`、`.local/`、`config.json` 或导出、备份文件。在线生成和对话会访问自行配置的服务，并可能产生费用。

## NovelAI 偏好

在「设置 → 通用 → NovelAI」中，可开关自动补全 Tag，选择 PNG 或无损 WebP 保存之后生成的作品。两种格式均可在 Vellum 中读回提示词与参数；已有作品保持原格式。偏好保存在当前浏览器中。

## Token 计数

使用未修改的公共模型词表在本机计算提示词 Token 数，随所选模型切换。公共词表中的词语属于模型资源，并非个人提示词模板。复杂强调语法和随机展开可能与服务端计数存在差异，界面计数仅供参考。
